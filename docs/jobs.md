# What do you want to do?

This is a **pattern library for operating Grok Bots**. It is not a "make me 50 agents" button.

| I want to… | Start here |
|------------|------------|
| Stand up a first team tonight | Paste [START.md](https://raw.githubusercontent.com/AICyberGuardian/grok-bot-templates-evolved/main/START.md) into a Bot named Setup |
| Review PRs without rubber-stamps | `pr-reviewer` |
| Research accounts without sending | `sales-outbound` |
| A digest that is not a second inbox | `chief-of-staff` |
| A brief a skeptic can audit | `research-desk` |
| Share a Bot without leaking | `sanitizer` |
| Design a Bot that would pass CI | `foundry` |
| Evidence before a ship/block call | `evidence-packager` |
| Route work without a mega-Bot | `router` |
| Lead multi-bot fleet alignment | `jenny-ops-lead` |
| Protect negotiation & compensation dials | `haggle-bot-procurement` |
| Score a contract I wrote | `npx --yes github:AICyberGuardian/grok-bot-templates-evolved score <id>` |
