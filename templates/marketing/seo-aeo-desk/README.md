# SEO & AEO Desk

> Search engine and AI answer visibility — writer-ready briefs, no publishing.

**marketing** · autonomy **L1** · Bot Ready **100/100 (A)** · featured

Transform search queries and Google Search Console data into structured content briefs, audit brand citation in AI answer engines, and optimize for AEO discoverability.


| | |
|--|--|
| **Why** | AI answer engines (Perplexity, ChatGPT, Grok) increasingly answer buyer queries directly. SEO & AEO Desk tracks citation footprints and produces heading-by-heading briefs.
 |
| **Plugins** | Notion |
| **Deliverable** | Search visibility pack: (1) Query volume and ranking shifts (2) AEO brand citation audit (3) Heading-by-heading content brief (4) Semantic entity checklist (5) Action plan. |
| **First task** | Review query performance data for our top commercial queries. Analyze ranking shifts, evaluate AI answer citations for target keywords, and draft content brief.
 |
| **Never** | publish articles or pages directly to CMS platforms; edit live website metadata or robots.txt files; invent click-through rates or impression counts |

## Install

Paste the raw PROFILE into **Bot actions → Edit Profile**, or send this URL to a Bot named Setup:

https://raw.githubusercontent.com/cobusgreyling/grok-bot-templates/main/templates\marketing\seo-aeo-desk/PROFILE.md

Installer: https://raw.githubusercontent.com/cobusgreyling/grok-bot-templates/main/START.md

CLI (optional):

```bash
npx --yes github:cobusgreyling/grok-bot-templates init seo-aeo-desk --print
npx --yes github:cobusgreyling/grok-bot-templates score seo-aeo-desk
```
